# Descubra seu Futuro — versão Python

Aplicação de quiz vocacional feita com Streamlit.

## Rodar no computador

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar gratuitamente na internet

1. Crie uma conta no GitHub e um repositório público chamado `descubra-seu-futuro`.
2. Envie os arquivos `app.py`, `requirements.txt` e `README.md` para esse repositório.
3. Entre em https://share.streamlit.io/ e conecte sua conta GitHub.
4. Selecione o repositório, a branch `main` e o arquivo principal `app.py`.
5. Clique em **Deploy**. O Streamlit fornecerá um link público para compartilhar.

O quiz não grava nem envia as respostas para um banco de dados; elas são processadas durante a sessão da aplicação.
